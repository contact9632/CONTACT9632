# CONTACT9632 — Royal Jewelry Collection

Elegant, responsive luxury jewelry boutique concept.

## How to preview
Open `index.html` in a modern browser. No build tools required.

## Pages
- `index.html` — home
- `collections.html` — catalog with filters and search
- `about.html` — brand story
- `gallery.html` — jewelry illustration gallery
- `contact.html` — demo inquiry form
- `faq.html` — questions
- `privacy.html` and `terms.html` — demo disclosures

## Features
- Responsive midnight blue / silver / white design
- Original local SVG jewelry artwork
- Search, filters, interactive demo bag (sessionStorage)
- Mobile navigation
- No dependencies or build process; optional Google Fonts

## GitHub Pages
Upload the *contents* of this folder to the root of a public GitHub repository. Go to Settings → Pages → Deploy from a branch → main → /(root).

## Important
All product designs, names and prices are illustrative. No live inventory, purchases, payments, shipping, or contact submission. The form only shows a demo notice. Do not represent the site as a functioning store until real business systems and legal policies are added.
